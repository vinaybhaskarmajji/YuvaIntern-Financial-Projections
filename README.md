## Key Highlights (Base Case)

- **Initial capital required:** only ₹15,000 – ₹17,000 (founder savings)
- **Break-even:** ~107 paying customers
- **Year 1 Revenue:** ~₹88,500 | **Net Profit:** ~₹48,600
- **Year 3 Revenue:** ~₹4.83 Lakh | **Net Profit:** ~₹2.18 Lakh
- No external funding needed in first 18–24 months
